📝 Project Description

This is a Product Management Web Application developed using Java Servlets, HTML, JDBC, and MySQL.
The project demonstrates CRUD operations and server-side processing using Servlet technology following a simple MVC-style approach.

It is designed as a learning and demo project for understanding Java web development.

🚀 Features

Add new product records

Store product data in database

Search product by Product ID

Display product list

Server-side form handling using Servlets

📂 Project Modules
🔹 Servlets

SaveRecordServlet

Handles product insertion

Reads form data

Saves record into MySQL database

SearchRecordServlet

Searches product by Product ID

Fetches record from database

ProductListServlet

Displays list of products

🔹 Frontend Pages

insert-record.html → Add new product

save-success.html → Success message after insertion

search-record.html → Search product by ID
